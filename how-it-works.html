✨ How Borrow Box Works

It is easy to use Borrow Box. Follow these steps:

1. Choose an Item 🔍

Look at the available items and choose the one you need.

2. Send a Request 📝

Go to the Borrow Now page and fill in the request form.

3. Use It Carefully 📚

Take care of the item while you are using it.

4. Return It ↩️

Return the item on the agreed date so another student can use it.
